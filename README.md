# AR Digital Solutions

A minimalist futuristic digital agency portfolio built with React, TypeScript, Vite, and Tailwind CSS.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React

## Features

- Responsive navigation
- Minimalist dark UI
- Hero section
- Services
- Featured projects
- Project filtering
- Project modal
- Project details pages
- About page
- Contact page
- Responsive design
- Mobile navigation
- Page loader
- Reusable components
- Centralized project/service data
